# Project 3D models

Per-LCSC STEP overrides used by `pcbkit attach-3d` **before** modelcdn.

Name files `{LCSC}.step` (e.g. `C399938.step` for the vertical USB-C plug).

`C399938.step` was generated from datasheet dims via
`parts/Jing_Extension_of_the_Electronic_Co_918_118A2021Y40006/make_step_model.py`
(CadQuery). It is not on EasyEDA/modelcdn yet.
